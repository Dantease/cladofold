# cf. artwork

The cladofold. mark follows the project owner’s CladoBook identity: lowercase cream `cf`, a square acid-lime period (target sRGB `#C6F542`), and a near-black background. The owner supplied the original reference and requested this adaptation. The selected master was created with image-generation assistance.

`cf-master.png` is the 1024 × 1024 master. `Scripts/MakeIcon.swift` produces the native macOS icon sizes and transparent rounded outer margins. The app and System Settings pane share this artwork. See [branding guidance](../../BRANDING.md) for modified forks.
