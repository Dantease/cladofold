# Branding

The official project is **cladofold.**: all lowercase, including the final period. Its icon is **cf.**, with cream letters and an acid-lime period.

Please give distributed, modified forks their own name and icon so users can tell them apart from the official app. You can credit cladofold. as the upstream project and link to this repository. Avoid implying that a fork is an official release or is endorsed by the project owner.
